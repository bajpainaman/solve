examples. Open a specific section only to resolve a named question after its
compact method card has proved insufficient. They are not active skill instructions.

isolation, budgets, and completion. Older always-run statements, phase schedules,
confidence points, roleplay fallbacks, and full-input reading rules in this directory
are superseded. Example dates, product behavior, costs, outcomes, and migration
