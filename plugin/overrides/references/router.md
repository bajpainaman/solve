# Portable routing

The entry point in [SKILL.md](../SKILL.md) owns routing. Load only the selected
mode: [decision](decision.md), [artifacts](artifacts.md), or [writing](writing.md).
Short answers need no ledger. A mixed request resolves an open consequential
choice before producing its artifact.

The plugin uses the original portable renderer. It does not run `html-sync` or
require an external HTML package. Use `bin/templates match "<request>" --portable`
for shape selection; examples are fictional structural references.
