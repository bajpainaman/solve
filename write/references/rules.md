# ASD-STE100 rule map, issue 9

This is a condensed working map of the 53 rules. Use the official standard for
exact compliance decisions.

## Section 1: words

1. **1.1** Use dictionary-approved words, technical nouns, or technical verbs.
2. **1.2** Use an approved word only as its specified part of speech.
3. **1.3** Use an approved word only with its approved meaning.
4. **1.4** Use only approved verb and adjective forms.
5. **1.5** Use nouns that fit an allowed technical-noun category.
6. **1.6** Use an unapproved dictionary word only as a technical noun or part of
   one.
7. **1.7** Do not use a technical noun as a verb.
8. **1.8** Use terminology accepted by the company, industry, or subject field.
9. **1.9** Select short technical nouns that are easy to understand.
10. **1.10** Do not use regional, slang, or jargon terms as technical nouns.
11. **1.11** Use one technical noun for one item.
12. **1.12** Use verbs that fit an allowed technical-verb category.
13. **1.13** Do not use technical verbs as nouns.
14. **1.14** Use American English spelling unless an official directive says
    otherwise.

## Section 2: multi-word nouns

1. **2.1** Keep a multi-word noun to no more than three words.
2. **2.2** If a technical noun has more than three words, write it in full first.
   Then define a short form or use clear hyphenation.

## Section 3: verbs

1. **3.1** Use only dictionary-listed verb forms.
2. **3.2** Use the infinitive, imperative, simple present, simple past, simple
   future, or a permitted past participle used as an adjective.
3. **3.3** Use a past participle as an adjective only where permitted.
4. **3.4** Do not build complex verb constructions with auxiliary verbs.
5. **3.5** Use an `-ing` form only as a technical noun or a modifier in a
   technical noun.
6. **3.6** Use active voice. In descriptions, use passive voice only when the
   actor is unknown.
7. **3.7** Describe an action with an approved verb rather than a noun or another part
   of speech.

## Section 4: sentences

1. **4.1** Write short, clear sentences.
2. **4.2** Do not omit necessary words or use contractions to shorten text.
3. **4.3** Use a vertical list for complex text.
4. **4.4** Use connecting words or phrases for sentences with related topics.
5. **4.5** Use `a`, `an`, `the`, `this`, or `these` before a noun when needed.

## Section 5: procedural writing

1. **5.1** Limit each sentence to 20 words.
2. **5.2** Put one instruction in each sentence unless actions occur at the same
   time.
3. **5.3** Write instructions in the imperative form.
4. **5.4** Put a necessary condition first, then separate it from the command
   with a comma.
5. **5.5** Use notes for information only, never for instructions.

## Section 6: descriptive writing

1. **6.1** Give information gradually.
2. **6.2** Use key words and key phrases to create a logical structure.
3. **6.3** Limit each sentence to 25 words.
4. **6.4** Put related information in paragraphs.
5. **6.5** Keep one topic in each paragraph.
6. **6.6** Limit each paragraph to six sentences.

## Section 7: safety instructions

1. **7.1** Use a word or symbol that identifies the risk level.
2. **7.2** Start with a clear command or condition.
3. **7.3** Explain the risk or possible result.

Use `WARNING` for injury or death. Use `CAUTION` for damage to objects. If both
risk levels exist, use `WARNING`.

## Section 8: punctuation and word count

1. **8.1** Use standard English punctuation except the semicolon.
2. **8.2** Use hyphens to connect words that function together.
3. **8.3** Use parentheses only for defined functions: references, identifiers,
   work-step markers, abbreviations, singular/plural forms, explanations, or
   alternatives.
4. **8.4** In a vertical list, a colon ends a sentence for word-count purposes.
5. **8.5** Count parenthetical text as one word in its sentence.
6. **8.6** Count each number, number-plus-unit, abbreviation, alphanumeric ID,
   quotation, title/label, or proper name as one word.
7. **8.7** Count a hyphenated word as one word.

## Section 9: writing practices

1. **9.1** Change the sentence construction when word-for-word replacement is
   not sufficient.
2. **9.2** Use each approved word correctly.
3. **9.3** Do not combine words into phrasal verbs.
4. **9.4** Keep terminology and wording consistent.

## General recommendations

These recommendations are not STE rules:

1. Use `that` when it makes the boundary of a subordinate clause clear.
2. Review `with` for ambiguity: association, accompaniment, or instrument.
3. Use pronouns only when the antecedent is unambiguous.
4. Make the referent of `this` explicit.
5. Check false friends against the intended English meaning.
6. Prefer English phrases to Latin abbreviations such as `e.g.`, `i.e.`, and
   `etc.`.
7. Use gender-neutral and non-discriminatory language.
8. Use possessive forms only when they are clear and correct.
