# Writing practices

## Core idea

When a direct word replacement does not work, reconstruct the sentence. Keep
terminology and sentence logic consistent.

## Rule set

- Change the sentence construction when word-for-word replacement is
  insufficient.
- Use each approved word for the intended meaning.
- Do not create phrasal verbs.
- Use a consistent terminology and writing style.

## General recommendations

- Keep `that` when it makes a clause boundary clear.
- Review `with` for three meanings: association, accompaniment, or instrument.
- Replace an ambiguous pronoun with its noun.
- Make the referent of `this` explicit.
- Check words that resemble a word in another language but have a different
  English meaning.
- Prefer `for example`, `that is`, or a complete list to Latin abbreviations.
- Use gender-neutral language.
- Avoid possessive forms when the relationship is unclear.

## Worked example

Ambiguous:

> Install the agent with the default policy.

Possible meanings:

- Install the agent that already has the default policy.
- Install the agent and the default policy together.
- Use the default policy during installation.

Do not rewrite until you know the intended relationship.
