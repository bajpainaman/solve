# Reference cards licence

The cards in this directory adapt and summarise text from the Centre for DPI's
[docs](https://github.com/centre-for-dpi/docs) (https://docs.cdpi.dev/), pinned in `../sources.json`.
That text is licensed under Creative Commons Attribution-ShareAlike 4.0 International
(https://creativecommons.org/licenses/by-sa/4.0/). These cards are shared under the same licence.
Each card names the pages it draws from. Changes: condensed, reorganised into review procedures, and
translated from government examples into general software practice.

The ai-skills repository (https://github.com/centre-for-dpi/ai-skills) publishes no licence. `bin/cdpi sync`
fetches it into a local cache for lookup; this project never copies or redistributes it.
